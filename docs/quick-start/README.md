# LARGE-PRINT QUICK START

These guides use short steps and work when AI is unavailable.

Make this page larger:

1. On Windows, press **Ctrl and +**.
2. On a Mac, press **Command and +**.
3. Stop when the words are easy to read.

These are Markdown guides. For large print, use 200% browser zoom or choose
a large font in your viewer before printing. Print size depends on that viewer.
Use the path shown in a guide after your SeniorSocial site's address.

Choose your guide:

- [Resident guide](resident.md)
- [Caregiver guide](caregiver.md)
- [Staff and admin guide](staff-admin.md)

Need help? Open the site's `/help` address. In Easy Mode, shell pages show
**Help me** and **Call a person** at the bottom. Both open the help page;
**Call a person** does not start a phone call. Some pages are outside this shell.
